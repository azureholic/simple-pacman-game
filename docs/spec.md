# Pacman

A browser-only Pacman game implemented as a React frontend with no backend required.

## Scope
- Must run entirely in the browser with no custom backend services.
- Implemented using React.
- Must be deployable as static assets.

## Out of Scope
- Server-side persistence (e.g. global leaderboards).
- External authenticated APIs.

## Clarifications
- **What browser versions and screen sizes must be supported (e.g. desktop only, or mobile responsive)?**: desktop only
- **Should sound effects and music be included?**: not needed
- **What level layout is expected (e.g. the classic maze, a single test level, or multiple levels)?**: classic maze
- **Is localStorage for high scores required, or should no persistence be implemented at all?**: no persistence
